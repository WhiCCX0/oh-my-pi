All new arms use the same pinned upstream, Bun 1.4.5, localization, and native-only packaging. Compare D16/E16/H16 with B; D1/E1/H1 with C. D uses full Raptor Lake target (local hardware only); do not execute it on unknown hosted CPUs. E changes only external Windows clang-cl/lld-link on the Linux x64 build host. The hosted smoke receipts for D explicitly say local-hardware-required, not runtime pass. For E/H require the correct loaded addon hash. The collector allows partial success and records missing arms. No release changes. After completion, pin the actual new EXE and addon hashes in the extended local benchmark before using them. Existing four-arm benchmark is not suitable for the expanded matrix.
